# Cloud-Based File Upload & Sharing System

This project is a web-based application designed to provide users with a secure and efficient platform for uploading, storing, and sharing files over the internet. It demonstrates the practical implementation of cloud computing concepts in file management systems.

## Features
- User registration and login system
- Secure file upload and storage
- File access from anywhere
- File sharing functionality
- Database management for file records

## Technologies Used
- HTML, CSS, JavaScript (Frontend)
- PHP (Backend)
- MySQL (Database)
- XAMPP (Server)

## Objective
The main objective of this project is to develop a system that reduces dependency on physical storage devices and provides secure, reliable, and easy file access through cloud-based technology.
